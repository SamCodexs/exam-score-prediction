Exam Score Prediction Using Linear Regression

Project Overview: This beginner-friendly machine learning project uses Linear Regression to predict students' exam scores based on the number of hours they study.

Objective: To explore the relationship between study hours and exam scores and learn the basic machine learning workflow.

Technologies Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

Dataset: The notebook uses a small example dataset containing study hours and exam scores. The data is for learning and demonstration purposes.

Methodology
1. Create and organize the example dataset using Pandas.
2. Select study hours as the input feature and exam scores as the target.
3. Train a Linear Regression model.
4. Generate predicted scores.
5. Evaluate predictions using Mean Absolute Error (MAE).

How to Run
1. Install Python and the required libraries.
2. Open "exam_score_prediction.ipynb" in Jupyter Notebook or VS Code.
3. Select a Python kernel.
4. Run the notebook cells from top to bottom.

Limitations: This project uses only five example data points. Its predictions are for educational demonstration and should not be treated as reliable predictions of real students' performance.
